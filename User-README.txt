Cinematic Noir: your own sounds

Put WAV files here, then tap RESCAN on the plugin screen (or reload the plugin).

- A folder of WAVs is one multisampled instrument. Each file's root note comes from the end of its name:
  a note name (Piano C3.wav, Pad F#2.wav, with C3 = MIDI note 60) or a MIDI number (Piano 060.wav).
- A WAV directly in this folder is a one-shot, played from C3 (or from the note in its name).
- Loop points saved in the WAV are used. Any bit depth and sample rate.
- Your sounds appear in every mode, after the built-in ones. Updates of the plugin keep this folder.
